# 便携副本托盘修复与重启验证（2026-11-22）

## 原因与改动

项目输出目录的低完整性标记被本地 EXE 继承，导致从资源管理器启动的进程无法正常注册系统托盘图标。根目录 EXE 修复后，`dist/DeskDecor-portable-x64/DeskDecor.exe` 仍有相同标记。

- `build.ps1` 在编译后将 EXE 标记为 Medium integrity；失败时明确报错。
- `package.ps1` 同步生成可运行的本地便携目录，设置目录及 EXE 的 Medium integrity，只更新分发文件，保留本地配置和个人内容。
- 本地便携 EXE 被占用时拒绝更新，且在此情况下不替换分享 ZIP。
- 中英文 README 说明运行位置、普通用户 PowerShell 构建要求，以及 ZIP 不保存 Windows 完整性标记的限制。

## 已完成验证

已完成构建、打包、占用检查、配置保留和 ZIP 内容核对；实机通过隐藏图标面板中的黑黄图标验证了右键菜单、管理窗口、关闭后驻留及双击图标重新打开设置。随后正常退出程序并从资源管理器重新启动。

重启后的最终检查：

- 唯一运行副本为 `dist/DeskDecor-portable-x64/DeskDecor.exe`。
- 进程完整性为 `0x2000`（Medium）。`Shell_NotifyIconGetRect` 成功返回图标 ID 1 的矩形，确认重启后的托盘注册成功。
- 双击本地便携 EXE 正常唤醒“桌面小组件”管理窗口。点击“完成”后管理窗口收起，程序继续运行，托盘注册仍成功。
- 通过 SHA-256 核对，配置和 `.bak` 均与退出前一致。
- 独立只读审查确认便携 ZIP 恰好包含六个分发文件，逐项与当前产物一致；根目录、本地便携目录和 ZIP 中的 EXE 哈希一致。源码 ZIP 的脚本及文档与工作区一致，分享包不含个人配置、备份、日志和迁移文件。

程序留在运行状态。Windows 可以将托盘图标放在右下角 `^` 隐藏图标面板中。

## 限制

ZIP 不保存 Windows 完整性标记；若在其他低完整性目录重新解压，仍可能继承低完整性标记。本轮验证针对当前本地便携目录，不包含其他电脑、系统重启或其他解压目录的实测。
