# 本地升级实机验证 — 2026-11-22

本文件记录 1.1.0 的历史行为。用户随后要求迁入个人文件并清空旧目录（包括备份），1.1.1 的最新实机结果见 [全量迁移与清理记录](full-cleanup-live-2026-11-22.md)。

## 结果与范围

在当前用户的实际 Windows 桌面上验证了本地配置迁移流程，使用独立临时目录、合成文件和真实 DeskDecor 窗口。新版从便携包解压运行，未替换用户正在使用的正式 EXE。测试前暂时正常退出正式程序，结束后恢复正式程序、主配置、滚动备份和安装位置记录；配置与 EXE 的 SHA-256 均与测试前一致。最后仅正式进程在运行，无测试进程残留。

实机测试覆盖当前单屏 1920×1080、125% 缩放环境。没有把隔离窗口回归或合成程序集测试算作这里的桌面实测。

## 已实际执行

| 场景 | 过程及结果 |
| --- | --- |
| 支持交接的旧版 | 将同一实现仅降低程序集版本为 1.0.0.0，放入独立旧目录，使用 2 个分组、3 个入口、图标 28、透明度 85。实际启动旧版，再运行解压后的 1.1.0.0 新版。旧进程正常保存退出，新版接管并显示原配置。这里的 1.0.0.0 是交接测试版本，并非已发布的历史版本。 |
| 主配置和备份 | 自动交接后，新旧主 XML 和滚动备份分别逐字节一致。分组标题、入口路径、显示名称、顺序和外观保留。 |
| 旧 EXE 清理 | 新版保持正常运行后，旧 EXE 被删除；新版 `.migration/migration-backup-*` 中的 EXE 和 XML 与旧文件哈希一致。旧目录的配置及合成个人文件保留。 |
| 真实早期旧版 | 使用保存的原始便携 EXE，程序集版本 0.0.0.0，SHA-256 为 `D1F7E491001B060E1539F084CD96752B15E90EC3C778E08B8018EF54AF723EA2`。新版实际显示“先从旧版托盘退出”提示，未提前生成新配置或删除旧 EXE。用户实际从托盘退出后，再运行新版，成功从已记住的目录迁移两个入口和原分组标题。 |
| 早期配置兼容 | 新版管理窗口显示原来的“早期旧版·保留配置”分组和两个入口。早期格式缺少的图标大小、透明度等字段使用正常默认值；位置按现有 DPI 恢复逻辑处理。旧 XML 和 EXE 都已备份。 |
| 实际桌面渲染 | 在真实管理窗口检查迁移后的入口与外观，并用现有 SurfaceInspector 查看 DWM 合成缩略图。返回 `DWM=0 Cloaked=0`，可见迁移后的透明分组、标题和图标。该缩略图证明实际合成内容，不将其称为完整桌面截图。 |
| 多份配置 | 同时提供运行中的早期旧版和已记住的另一个有效目录。实机显示两个来源；不预选来源，“使用所选配置”按钮默认禁用。取消后没有生成配置，两个旧 EXE 保留。选择其中一个目录后，只迁移选中配置，未选中的旧 EXE 保留。 |
| 新版重启 | 正常退出后再次运行迁移完成的新版，主配置 SHA-256 不变，没有重复生成迁移备份，也没有残留待完成迁移记录。 |

## 本轮调整

多来源分支原先弹出文件浏览器，要求用户再次找到已识别的 EXE。改为直接列出已发现的旧目录，必须明确选择后才能继续。调整后的选择、取消和实际迁移均已在桌面验证。

## 自动化及分发检查

调整后完整运行 `tests/run.ps1` 通过，包含旧配置迁移、损坏主配置读取有效备份、来源重新校验、版本筛选、源码/Git 目录保护、文件变化保护，以及真实应用消息窗口的保存退出事件链。自动化异常场景不冒充实机异常注入。

重新构建并生成便携包，核对包内 EXE 与实机候选相同，源码与工作区对应。包只包含 EXE、两份 README、许可、第三方说明和源码 ZIP；没有个人 XML、迁移备份、后台下载或 ZIP 导入功能。

本轮没有在其他电脑、其他权限账户、真实多显示器或断电条件下测试。不支持交接的早期版本仍需首次手动从托盘退出。
